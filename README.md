# VSCode File Editor

在 VS Code 中可视化编辑 HTML 源码，也可以打开 PowerPoint 演示文稿并修改其中的文字。保存由 VS Code 管理。

## 安装

在扩展视图搜索 **VSCode File Editor**，或在 VS Code 快速打开窗口运行 `ext install pengsen.vscode-visual-html-designer`。使用 Remote SSH 时，在已连接的窗口选择将扩展安装到远程主机。

### 使用 VSIX 安装到 Remote SSH 服务器

1. 在 VS Code 连接 Remote SSH 主机，打开服务器上的项目目录。
2. 在已连接的远程窗口打开扩展视图，选择 **Views and More Actions → Install from VSIX...**，选中发布包。确认扩展出现在 **SSH: 主机名** 下。
3. 如果使用服务器终端安装，可先把 VSIX 上传至服务器，再在 VS Code 远程集成终端运行 `code --install-extension ./pengsen.vscode-visual-html-designer-0.2.15.vsix`。

扩展进程在工作区所在的主机运行，可视化界面由桌面 VS Code 显示。打印时通过 VS Code 的端口转发打开浏览器。

## 标题快捷键

在 HTML 或 PowerPoint 的编辑画布中，将光标放在段落里，按 `Ctrl+Alt+1` 到 `Ctrl+Alt+6` 可应用对应级别的标题。再按一次相同的组合键可恢复正文。HTML 使用 H1 到 H6 标签，PowerPoint 使用对应的加粗字号。

## 编辑 PowerPoint

1. 在资源管理器右键单击 `.pptx`，选择 **PowerPoint Editor: Open Presentation**。也可以从 **打开方式…** 中选择 **PowerPoint Editor**。
2. 上下滚动左侧缩略图并点击切换幻灯片，也可以用方向键或 Page Up / Page Down 翻页。
3. 单击画布中的标题、正文或表格文字，即可在光标处输入、删除、粘贴或换行。用顶部工具栏调整光标所在段落的字体、字号、粗体、斜体、下划线、删除线、颜色、高亮和对齐。**Edit text** 可打开侧栏文字字段。
4. 使用 **Save** 或 VS Code 的保存快捷键把文字和样式写回原 `.pptx`。可通过 VS Code 撤销、重做或另存为。

底栏支持滑块、加减按钮和 **Fit**。点击百分比可恢复到 100%，也可以在幻灯片画布上按住 Ctrl（macOS 为 Command）滚动鼠标滚轮缩放。

- 顶部 **Insert** 可插入文本框、矩形、圆角矩形、圆、椭圆、三角形、菱形和右箭头。选择后单击放置，或拖动指定大小。
- 双击幻灯片空白处会新建文本框并立即进入输入。顶部还支持增减字号、上下标、项目符号、数字编号、缩进和行距。
- 点顶部 **Select** 显示对象边界，拖动框住要选中的对象，或在 **Objects** 列表勾选。可批量删除空文本框、隐藏对象和普通形状，按 **Delete** 或点顶部 **Delete** 即可删除，支持撤销。

幻灯片画布用于定位文字，复杂图表、动画和母版效果请在 PowerPoint 中查看。编辑器保留原文稿中的这些内容以及备注和媒体文件。旧版 `.ppt` 请先用 PowerPoint 或 LibreOffice 另存为 `.pptx`。

## 编辑 HTML

- 在资源管理器右键单击 `.html` 或 `.htm`，选择 **打开方式… → VSCode File Editor (HTML)**。要设为默认，选择同一列表里的 **配置默认编辑器…**，再选 **VSCode File Editor (HTML)**。
- 打开 HTML 文件，点击编辑器右上角的预览按钮，或执行 **HTML Editor: Open Design View**。设计视图默认最大化。
- 点击画布即可编辑。工具栏支持段落样式、字体、字号、文本格式、对齐、列表、颜色、插入链接、图片、媒体、表格和符号。
- 将鼠标移到段落或标题上，或把光标放进去，点击左侧的 **+** 可在该段下方插入空白段落并开始输入。
- 粘贴富文本时沿用当前位置的字体、字号和颜色，同时保留段落、列表、表格及加粗、斜体等格式。
- 段落图标显示光标所在的标题级别。点击图标可选择 H1 至 H6 或 Normal，同时修改段落标签、字号和粗细。
- 工具栏末尾的统一标题图标会把当前页面所有 H1 至 H5 的字号和粗细统一为插件对应级别的样式。
- 点击字号图标并选择 **Custom…** 可输入像素字号。选中文字时应用到选区，光标停在段落里时应用到当前段落。
- 左侧目录按正文顺序列出 H1 至 H6，并根据级别嵌套。点击标题可跳到正文，点击箭头可折叠子标题，工具栏左侧的目录按钮可收起整个侧栏。
- 鼠标或编辑光标在正文中移动时，目录会高亮对应章节。子标题被折叠时会高亮可见的上级章节。
- 左右拖动目录和正文之间的分隔线可以调整目录宽度。分隔线获得焦点后也可以用左右方向键调整。
- 目录默认显示 H1 至 H3。用目录按钮旁的筛选图标可调整显示层级，选择会记到下次打开 HTML。
- 单击目录中的页内链接即可跳到对应标题。
- HTML 默认以 85% 显示。在画布上按住 Shift 滚动鼠标滚轮可缩放页面。底栏支持直接输入百分比、拖动滑块和加减。点击重置图标可恢复到 85%。
- 点击工具栏上的字体颜色或文字背景色图标可打开色板。点击色块或输入完整的六位十六进制色值后立即应用。
- 底栏的 **HTML** 打开正文 HTML 编辑框，**Full screen** 切换最大化和并排布局，**Print / PDF** 打开浏览器的打印对话框。
- `htmlDesign.syncDelay` 可以调整可视化修改写回源码的延时，默认 300 毫秒。
- 静态页面会加载文档头部的样式以及相对路径资源。画布与打印视图禁用页面自身的脚本。
- 源码在可视编辑尚未同步时被修改，设计视图会保留草稿。可以复制草稿，再重新加载最新源码。

## 开发

在此目录运行 `npm ci`。在 VS Code 中打开此目录并按 F5 启动扩展开发宿主。运行 `npm test` 执行测试，运行 `npm run package` 生成 VSIX。
